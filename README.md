# Achats filiales HM Group

Mini-CRM responsive pour préparer, répartir et suivre les commandes fournisseurs de CPTE Conseil, HM Pose, HM Instal et HM PAC.

## Fonctionnalités

- tableau de bord synthétique ;
- création de commande guidée en quatre étapes ;
- calcul du dispatch par société selon le nombre d’équipes ;
- bon fournisseur sans affichage du nombre d’équipes ;
- catalogue produit unique avec références et prix par fournisseur ;
- suivi des commandes, utilisateurs et paramètres essentiels ;
- interface adaptée aux ordinateurs et aux téléphones.

## Lancer le projet

```bash
npm install
npm run dev
```

## Production

```bash
npm run build
```

Le projet utilise React, TypeScript, Vinext et Vite.
